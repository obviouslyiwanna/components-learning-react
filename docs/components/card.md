# Card

`Card` 提供标题区和内容区，用于组织一组相关信息。

## 基础使用

```jsx
<Card title="周末灵感">
  <p>去公园散步，记录今天看到的三种颜色。</p>
</Card>
```

## Props

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `title` | `ReactNode` | 卡片标题内容 |
| `children` | `ReactNode` | 卡片正文内容 |

`title` 对应原生版的 `title` 具名插槽，`children` 对应默认插槽。

## 当前限制

- 当前没有边框、阴影、内边距等外观变体。
- 标题为空时仍会保留标题区域的下方间距。
